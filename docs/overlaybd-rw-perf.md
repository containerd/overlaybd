# OverlayBD 可写层随机读写性能参考

## 测试环境
  - instance: ecs.ebmc8i.48xlarge
  - cpu: Intel(R) Xeon(R) Platinum 8475B
  - mem: 512G
  - disk: ESSD-PL3 (8TB / ~411K iops)

## 测试方法
  通过创建 overlaybd-ublk 设备，固定单硬件队列、nr_tags=64:
  - 随机读写：使用 /dev/urandom 写入20GB数据，使用 fio iodepth 分别为 1/16/32/64 对20G数据进行4K随机读写测试
  - 顺序读写：dd bs=1M count=20480 oflag=direct conv=fdatasync
