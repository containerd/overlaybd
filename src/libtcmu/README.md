# Photon-libtcmu

Photon-libtcmu is a PhotonLibOS-based implementation of libtcmu. It is derived
from [tcmu-runner](https://github.com/open-iscsi/tcmu-runner) and contains only
the libtcmu-related subset, without the tcmu-runner daemon, handlers, or backing
stores. The retained code has been adapted to use
[PhotonLibOS](https://github.com/alibaba/PhotonLibOS).
